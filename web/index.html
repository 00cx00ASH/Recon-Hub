Como entrar

O recon-hub nasce fechado. Você precisa do token de acesso uma única vez (o navegador guarda depois).

⚠ O token guardado foi rejeitado. Provável: o servidor reiniciou e gerou outro. Pegue o novo abaixo.

  1. No terminal onde o servidor está rodando, procure estas linhas no log: 
    token gerado e salvo em /.../recon-hub/data/token
┌─────────────────────────────────────────────
│ abra no navegador:  http://127.0.0.1:7878/#token=<SEU_TOKEN>
└─────────────────────────────────────────────
  2. Jeito mais fácil: copie a linha http://127.0.0.1:7878/#token=… inteira e abra no navegador. Pronto — o hub guarda o token e limpa a URL.
  3. Ou pegue o token e cole aqui: 
    # local:
cat data/token
# docker:
docker compose exec reconhub cat /app/data/token
